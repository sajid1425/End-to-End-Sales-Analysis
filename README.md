📊 End-to-End Sales Analysis (2014–2018)

A complete data analysis workflow using Python, Jupyter Notebook, Power BI, and Excel.

📁 Project Overview

This project performs an end-to-end sales analysis on a U.S. retail dataset (2014–2018).
It includes data profiling, cleaning, EDA, trend & seasonality analysis, outlier detection, and customer segmentation, followed by visual storytelling through a Power BI dashboard and an executive summary presentation.

The goal is to uncover actionable insights that support sales optimization, pricing decisions, and customer targeting.

✅ Key Objectives

Understand sales trends across years, regions, categories, and customers

Detect seasonality and identify peak revenue windows

Identify outliers affecting revenue or unit economics

Segment customers using revenue and margin patterns

Build an interactive Power BI dashboard for decision-makers

Present insights in a structured and business-friendly format

🧰 Tools & Technologies

Python (Jupyter Notebook): pandas, numpy, matplotlib, seaborn/plotly

Power BI: dashboard/report creation

Excel: data cleaning & exploration

PowerPoint: insights presentation
